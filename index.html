嵌入式调试，AI 与人同时在线

板卡标准口（串口 · 网口 · Upgrade · 电源）经 Kit 服务化； 人与 AI 可用 HTTP 转串口 或 网口 SSH 控板，并行不互斥。

核心亮点 设计框图 下载
01

同一台主机，AI 与人并肩

人与 AI 都在调试主机上，共用 Kit，对接板卡 × N——各走各的通道，并行不互斥。

  • AI：HTTP→串口控板，也可网口 SSH
  • 人：Web / SSH；异常时可随时介入
  • 电源 / Upgrade 经继电器；串口经 ssh-bridge；网口 SSH 直连
02

分布式部署，远程也能协同

人与 AI 不在调试主机；Kit + 板留守现场，经 LAN / VPN / frp 远程接入，协同方式不变。

  • 远程 AI：HTTP→Kit→串口；也可网口 SSH
  • 远程人：Web / SSH 旁观与介入
  • 两条路始终可用：路径① 网口 SSH · 路径② HTTP→串口
Design

产品设计框图

人 / AI → Kit → 多板卡。AI 控板两条路：网口 SSH（高效）与 HTTP→串口（底层，无网可调 BL2/U-Boot/内核）。

Deploy

部署形态

场景一：人 / AI / Kit 同机。场景二：人 / AI 远程，Kit + 板留守现场。协同方式相同。
