嵌入式调试，AI 与人同时在线

板卡、AI Agent、工程师可以在不同机器、不同网段协同工作。 硬件时序与串口数据面分离，自动化与人工介入并行不互斥。

核心亮点 架构图 下载
01

同一台主机，AI 与人并肩

工程师与 AI Agent 都在调试主机上，同时连 relay / bridge——各走各的通道，目标却是同一块板子。

  • AI 跑 HTTP 流水线，人开 Web 看串口输出
  • 异常时人 SSH 介入，不中断 AI 已启动的流程
  • 板卡网口 SSH：人 / AI 均可直连
02

分布式部署，远程也能协同

调试主机接板子，AI 与工程师可在远端；通过 VPN 访问同一套 relay / bridge，协同方式不变。

  • 远程 AI HTTP 控板，远程工程师 Web 旁观
  • 跨网段访问板卡网口时，人 / AI 均可经可选跳板
  • 同网段则直连，无需跳板
Architecture

AI 与人协同调试

两种部署形态：同一台主机上并肩协作，或分布在不网段/不同机器上远程协同。AI 走 HTTP 自动化，人走 Web / SSH，并行不互斥。
