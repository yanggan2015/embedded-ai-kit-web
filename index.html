嵌入式调试，AI 与人同时在线

板卡、AI Agent、工程师可以在不同机器、不同网段协同工作。 硬件时序与串口数据面分离，自动化与人工介入并行不互斥。

两大亮点 架构图 下载
01

人机双轨，各走各的路

同一套服务，为 AI 和工程师打开不同通道——自动化不牺牲可观测性。

  • AI 走 HTTP：relay 控电源/烧录，bridge 串口发令读回
  • 人 走 Web / SSH：点按、旁观串口状态、交互 Console
  • AI 在跑流水线，工程师随时打开 Dashboard 看执行情况
02

真正分布式，不受工位束缚

调试主机接板子，AI 可在本地也可在远端；跨网段时经可选跳板到达板卡网口。

  • 远程 AI 通过 HTTP 调用调试主机上的 relay / bridge
  • 远程工程师 Web 旁观、SSH 介入，与 AI 并行
  • 板卡网口 SSH：人 / AI 均可访问；同网段直连，跨网段经跳板
Architecture

分布式调试架构

HTTP 归 AI 自动化，Web / SSH 归人工；relay 管硬件时序，ssh-bridge 管串口数据面。

👤 人工通道

  • relay / bridge Web：点按、旁观串口状态
  • SSH → 串口：交互式 Console
  • SSH → 板卡网口：系统起来后登录（同网段直连，跨网段经跳板）

🤖 AI Agent 通道

  • relay HTTP API：上电、reset、upgrade_mode
  • bridge 串口 HTTP：发令、读回、闭环
  • SSH → 板卡网口：自动化部署与验证（可经跳板）
  • Agent 可本地或远程，统一走 HTTP / SSH
